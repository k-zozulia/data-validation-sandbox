# Data Validation Sandbox

Вебсистема для інтерактивної декларативної валідації та автоматизованого
профілювання якості даних у пакетному режимі. Дозволяє завантажити файл,
автоматично отримати його профіль і чернетку правил, інтерактивно уточнити
правила та застосувати їх — спершу швидко на вибірці, потім повністю на всьому
наборі даних — без написання програмного коду.

Магістерський інженерний проєкт (MSc Computer Science, Neoversity).

## Можливості

- Приймання файлів у форматах **CSV, JSON, Parquet** (формат перевіряється за
  сигнатурою вмісту, а не лише за розширенням).
- Автоматичне **профілювання**: типи колонок, частка пропусків, кардинальність,
  діапазони, ознака масиву, кількість повних дублікатів рядків.
- Генерація **стартового набору правил** на основі профілю.
- **Декларативні правила** у форматі YAML; редагування через візуальний
  конструктор або текстовий редактор із підсвічуванням синтаксису.
- Сім типів перевірок: `not_null`, `dtype`, `range`, `unique`, `regex`
  (із захистом від ReDoS), `array_length`, `array_items`.
- **Швидка перевірка на вибірці** (миттєвий зворотний зв'язок) та
  **повний асинхронний прогін** по всьому набору даних.
- **Експорт** коректних і карантинних даних; у карантинний файл додається
  стовпець із причинами відбракування.

## Технології

- **Backend:** Python, FastAPI, pandas, pyarrow, Celery, Redis, pytest
- **Frontend:** React, TypeScript, Vite, CodeMirror, recharts
- **Інфраструктура:** Docker, Docker Compose

## Запуск

### Передумови

- Docker і Docker Compose
- Node.js 18+ (для клієнтської частини)

### Серверна частина

```bash
docker compose up --build
```

Піднімається три сервіси: `redis`, `api` (порт 8000) та `worker`.
Інтерактивна документація API: <http://localhost:8000/docs>.
Перевірка стану: <http://localhost:8000/health>.

### Клієнтська частина

```bash
cd frontend
npm install
npm run dev
```

Інтерфейс: <http://localhost:5173>.

### Тести

```bash
docker compose run --rm api pytest
```

## Приклад використання

1. Відкрити інтерфейс і завантажити файл (CSV, JSON або Parquet).
2. Натиснути **Profile** — з'явиться профіль даних і чернетка правил.
3. Уточнити правила у конструкторі або в редакторі YAML.
4. Натиснути **Validate sample** — швидка перевірка на вибірці.
5. Натиснути **Run full** — повний асинхронний прогін по всьому набору.
6. Завантажити результати: `clean.csv` та `quarantine.csv`.

## Структура проєкту

```
backend/
  app/
    main.py              точка входу FastAPI
    config.py            налаштування та ліміти
    models/              схеми даних
    parsers/             розбір CSV / JSON / Parquet + визначення формату
    validators/          рушій правил і валідатори
    services/            профілювання, генерація правил, сховище
    routers/             ендпоінти API
    workers/             асинхронний воркер (Celery)
  tests/                 автоматичні тести
frontend/
  src/
    api/                 клієнт до API
    components/          конструктор правил, редактор, дашборд, таблиця
docker-compose.yml       redis + api + worker
```

## API (основні ендпоінти)

- `GET  /health` — стан сервісу та Redis
- `POST /datasets/profile` — профілювання файлу та стартові правила
- `POST /datasets/validate-sample` — швидка перевірка на вибірці
- `POST /jobs` — запуск повного асинхронного прогону
- `GET  /jobs/{id}` — стан і результат завдання
- `GET  /jobs/{id}/export/{kind}` — експорт (`clean` | `quarantine`)
